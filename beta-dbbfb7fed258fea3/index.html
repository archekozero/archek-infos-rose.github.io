Installer

  1. Clic droit sur Rose-2.3.zip → Extraire tout.
  2. Dans le dossier extrait, double-clique sur Rose-Setup.exe (pas besoin de droits administrateur).
  3. Si Windows affiche « Windows a protégé votre PC » : Informations complémentaires → Exécuter quand même. Rose est nouvelle, Windows ne la connaît pas encore.
  4. Dis « Rose », puis ton ordre. Clic droit sur Rose → Tutoriel pour la visite guidée. Tout est expliqué dans LISEZ-MOI.txt, dans le zip.

Ensuite, Rose se met à jour toute seule : à chaque nouvelle version de la bêta, elle la télécharge, vérifie qu’elle est intacte et redémarre à jour, réglages gardés.
Tu l’avais installée avant le 20 novembre au soir ? Réinstalle-la une dernière fois avec ce zip.
